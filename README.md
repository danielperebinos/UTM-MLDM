This repository contains practical assignments developed during the **Machine Learning and Data Mining** course at the
Master's level. The labs explore both **unsupervised** and **supervised** learning methods, focusing on clustering and
classification techniques using real-world datasets.

---

## 📘 Lab 1 – Clustering Techniques & Data Visualization

**Objective**: Apply and compare several clustering algorithms on numerical datasets and visualize the results in 2D
using PCA.

**Key Topics**:

- Preprocessing and normalization
- Dimensionality reduction using **PCA**
- Clustering algorithms:
    - **KMeans**
    - **Agglomerative Clustering**
    - **DBSCAN**
    - **Gaussian Mixture Models**
- Silhouette score evaluation
- Data visualization using **Matplotlib** and **Seaborn**

**Tools**: `scikit-learn`, `matplotlib`, `seaborn`, `pandas`

📁 File: `Laboratorul 1.ipynb`

---

## 📗 Lab 2 – Supervised Classification Algorithms

**Objective**: Build and evaluate classification models on the Titanic dataset using multiple supervised learning
approaches.

**Key Topics**:

- Data preprocessing and encoding
- Train/test split and PCA projection for visualization
- Classification models:
    - **Naive Bayes**
    - **Support Vector Machine (SVM)**
    - **Decision Tree**
    - **AdaBoost**
- Confusion matrix, precision, recall, F1-score
- Feature importance and decision tree visualization

**Tools**: `scikit-learn`, `pandas`, `matplotlib`, `seaborn`

📁 File: `Laboratorul 2.ipynb`
